# birt roadmap

Human-owned wish list. The planner agent turns these lines into tickets, at most 2 per day, only when fewer than 3 tickets are ready. Add or remove lines through a pull request. One wish per line.

- Posts: an index page that lists posts by date, plus one example post
- An RSS feed at /feed.xml
- sitemap.xml and robots.txt
- A print-friendly stylesheet
- Dark mode that follows prefers-color-scheme
- A skip-to-content link and visible keyboard focus styles
- A footer with a link to the repository
